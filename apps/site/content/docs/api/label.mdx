## Output

| Method | Returns |
| --- | --- |
| `toZPL()` | The ZPL, closed with `^XZ` if it isn't already |
| `lint()` | Problems the printer wouldn't report, as [`LintDiagnostic`](/docs/api/parsing#lintdiagnostic)s |
| `validate(strict?)` | Nothing; throws a `ZplError` for unclosed fields, and with `strict` (the default) for unknown commands |
| `commands` | The label's command nodes |

## Lower level

| Method | Adds |
| --- | --- |
| `add(...commands)` | Typed command nodes, as written. Nothing is escaped. |
| `raw(zpl)` | Plain ZPL, as written. Nothing is escaped, so keep user input out. |
| `open()`, `close()` | `^XA` and `^XZ`, for building several formats in one label |

## Units

Every length takes a unit, so millimeters and dots can't be mixed up.

| Function | Returns |
| --- | --- |
| `mm(value)` | A length in millimeters, converted with the label's `dpmm` |
| `dots(value)` | A length in printer dots, ZPL's own unit; whole numbers only |

Both throw a `ZplError` for negative numbers.

## Enums

`Orientation` sets which way text and barcodes run: `Normal`, `Rotated90Degrees`, `Inverted180Degrees` or `BottomUp270Degrees`.

`ZebraFontFamily` names the printer's fonts: `ZERO` for the scalable font 0, and `A` to `H` and `P` to `V` for the bitmap fonts.
