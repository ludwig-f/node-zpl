---
title: JSX
description: Write labels as JSX, in React projects or on their own.
---

Labels can also be written as JSX. It produces the same commands as the method calls, and `build()` returns the same `Label` object, with `toZPL()`, `lint()` and `commands`.

```tsx
import { Label, Text, Box, Code128, build, mm, dots } from "zplkit/jsx";

const order = { id: 10442, express: true };

const label = build(
  <Label width={mm(101.6)} height={mm(50.8)} dpmm={8}>
    <Text x={mm(5)} y={mm(5)} height={mm(7)}>
      Order #{order.id}
    </Text>
    <Box x={mm(5)} y={mm(16)} width={mm(91)} height={dots(3)} thickness={dots(3)} />
    <Code128 x={mm(5)} y={mm(20)} height={mm(13)}>
      {`ORD-${order.id}`}
    </Code128>
    {order.express && (
      <Text x={mm(66)} y={mm(5)} height={mm(7)}>
        EXPRESS
      </Text>
    )}
  </Label>
);

label.toZPL();
```

Text and barcode data go in children. The elements are `Text`, `Box`, `Code11`, `Code39`, `Code128`, `EAN13`, `Interleaved2of5`, `PDF417`, `DataMatrix`, `QrCode`, `Aztec`, `MaxiCode`, `Graphic`, `StoredGraphic` and `DefaultFont`, plus `<Field command="…">` for any other command and `<Raw zpl="…" />` for plain ZPL. `false`, `null` and `undefined` children are skipped, and lists from `.map()` work. Elements can be reused in labels with different resolutions, since millimeters are converted when the label is built.

## Your own components

Components are plain functions that return elements:

```tsx
// Position in millimeters, so lines can be placed relative to it
const ReturnAddress = (props: { x: number; y: number }) => (
  <>
    <Text x={mm(props.x)} y={mm(props.y)} height={mm(3)}>Harbor Parts Co.</Text>
    <Text x={mm(props.x)} y={mm(props.y + 4)} height={mm(3)}>1000 Shipping Lane</Text>
  </>
);

// <ReturnAddress x={5} y={40} />
```

`build()` also accepts a component that returns a `<Label>`, like `build(<ShippingLabel order={order} />)`.

## Setup

### React projects

No setup is needed. Label elements also work when compiled by React's JSX runtime, so labels can live next to your React components. Label components are plain functions that `build()` calls, not React components, so hooks and context don't work inside them.

### Without React

Tell TypeScript or your bundler to use zplkit's JSX runtime:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "zplkit"
  }
}
```

### Vue, Svelte and Angular

Their templates aren't JSX, so use the [method calls](/docs/building-labels) in a `.ts` file. If your build tool compiles `.tsx` files (Vite does), you can also keep labels in a `.tsx` file that starts with `/** @jsxImportSource zplkit */`.
