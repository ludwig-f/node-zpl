title: Rendering
description: Render ZPL to images in Node or the browser with @node-zpl/render.
---

`@node-zpl/render` draws ZPL the way a Zebra printer does, dot for dot, in plain TypeScript. It runs in Node and in browsers without WebAssembly or native modules, and powers [`<zpl-preview>`](/docs/preview) and the [playground](/playground).

```bash
npm install @node-zpl/render
```

```ts
import { renderZpl } from "@node-zpl/render";

// One base64-encoded PNG per label
const [png] = await renderZpl("^XA^FO50,50^A0,40^FDHello^FS^XZ", {
  widthMm: 101.6,
  heightMm: 152.4,
  dpmm: 8,
  grayscale: false,
});
```

`grayscale: false` gives the printer's dots exactly. `true` anti-aliases edges, which reads better on screen.

For the image data itself, `renderLabels` returns a raster per label, with ink coverage from 0 to 1 for each dot:

```ts
import { renderLabels, encodePng } from "@node-zpl/render";

const [raster] = renderLabels(zpl, { widthMm: 50, heightMm: 25, dpmm: 12 });
raster.width; // 600
raster.ink[0]; // 0 (no ink) to 1 (black)
const png = await encodePng(raster);
```

## What it draws

- Boxes, circles and diagonal lines (`^GB`, `^GC`, `^GD`), with rounded corners and white lines
- Images (`^GF`, `~DG` with `^XG`), including Zebra's compressed hex
- Text in font 0 and the bitmap fonts A to H (`^A`, `^CF`), rotated (`^FW`) and wrapped in blocks (`^FB`)
- Code 128, EAN-13, Code 11, QR codes and Data Matrix, with interpretation lines (`^BY`, `^BC`, `^BE`, `^B1`, `^BQ`, `^BX`)
- Reverse printing (`^FR`, `^LR`), label home (`^LH`), print width (`^PW`) and UTF-8 text (`^CI28`)

Commands it doesn't draw yet are listed per label by `layout()`, so you can warn about them.

## Accuracy

Zebra's built-in fonts can't be redistributed, so open-licensed fonts stand in for them: Archivo for font 0, stretched to font 0's measured letter widths, and DejaVu Sans Mono for fonts A to H. Text takes up the same space as on a printer, but letters look slightly different.

Everything else is checked against two other renderers, [Labelary](https://labelary.com) and [zebrash](https://github.com/ingridhq/zebrash). Shapes, images and barcode bars match Labelary dot for dot. Data Matrix symbols are the same size as a printer's, but may encode the data differently, which scanners read the same.
