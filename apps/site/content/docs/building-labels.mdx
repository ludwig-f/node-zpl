---
title: Building labels
description: Draw text, boxes, barcodes and images with typed method calls.
---

`Label` builds a label one element at a time. Each method returns the label, so calls can be chained, and `toZPL()` returns the finished ZPL.

```ts
import { Label, Orientation, mm, dots } from "zplkit";

const label = new Label({ width: mm(57), height: mm(19), dpmm: 12 })
  .drawText({
    position: { x: mm(2), y: mm(2) },
    text: "Organic Oat Drink",
    font: { height: mm(4) },
  })
  .drawEAN13({
    position: { x: mm(2), y: mm(8) },
    data: "735000123456",
    height: mm(7),
    orientation: Orientation.Normal,
  });
```

## Units

Every length takes an explicit unit: `mm(10)` for millimeters or `dots(80)` for printer dots, ZPL's native unit. Millimeters are converted with the label's `dpmm`. A bare number is a type error, so millimeters and dots can't be mixed up by accident.

## Elements

| Method | Draws |
| --- | --- |
| `drawText` | Text in a built-in or downloaded font |
| `drawBox` | Boxes and lines, optionally rounded or white |
| `drawCode11`, `drawCode39`, `drawCode128`, `drawEAN13`, `drawInterleaved2of5` | Linear barcodes |
| `drawPDF417` | PDF417 codes |
| `drawDataMatrix` | Data Matrix codes |
| `drawQrCode` | QR codes |
| `drawAztec`, `drawMaxiCode` | Aztec codes and MaxiCodes |
| `drawField` | A field with any command, for elements without a method |
| `drawGraphic` | An image, converted with `ImageConverter` |
| `drawStoredGraphic` | An image stored on the printer |
| `setDefaultFont` | The font for text that doesn't set one |

## QR codes

```ts
label.drawQrCode({
  position: { x: mm(2), y: mm(2) },
  data: "https://example.com/orders/10442",
  moduleSize: dots(5),
  errorCorrection: "Q",
});
```

`moduleSize` is the size of each square, and `errorCorrection` how much of the code can be damaged and still scan: L (7%), M (15%, the default), Q (25%) or H (30%).

## Escaping

Text and barcode data are escaped for you. Characters that ZPL would read as commands, `^` and `~`, are hex-encoded with `^FH`, so user input can't break a label:

```ts
label.drawText({ position: { x: dots(0), y: dots(0) }, text: "50% off ^ today" });
// ^FO0,0^FH^FD50% off _5E today^FS
```

## Images

`ImageConverter` turns a PNG or JPEG into a ZPL graphic. It runs in Node only, so it has its own entry point:

```ts
import { readFileSync } from "node:fs";
import { Label, mm, dots } from "zplkit";
import { ImageConverter } from "zplkit/image";

const graphic = await new ImageConverter().toZPL(readFileSync("logo.png"));

new Label({ width: mm(57), height: mm(19), dpmm: 12 })
  .drawGraphic({ position: { x: dots(0), y: dots(0) }, graphic });
```

## Commands without a method

For elements without their own method, `drawField` wraps any command in a field and escapes its data, so user input is still safe. For example, an EAN-8 barcode:

```ts
label.drawField({
  position: { x: mm(2), y: mm(2) },
  command: "^B8N,100,Y,N",
  data: "1234567",
});
// ^FO24,24^B8N,100,Y,N^FD1234567^FS
```

Labels are built from typed command nodes, which you can read with `label.commands`. Commands with a typed node but no method can be added with `add()`, and anything else as plain ZPL with `raw()`. Neither escapes anything, so keep user input out of `raw()`:

```ts
label.add({ type: "GraphicCircle", diameter: 80, thickness: 4 });
label.raw("^PQ2"); // print two copies
```
